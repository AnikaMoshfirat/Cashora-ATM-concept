ATM Management System
A simple ATM Management System developed as a full-stack web application.  
The system allows users to manage their accounts and perform ATM-related transactions through a user-friendly interface. It also includes an Admin Panel for managing users and system activities.

Features
User Features:
User Registration and Login
Secure Authentication
ATM Dashboard
Account Management
Deposit and Withdrawal
Transaction Management
View Transaction Information
User-friendly interface

Admin Features:
Admin Login
Admin Dashboard
Manage Users
Monitor system activities
Manage ATM-related information

Technologies Used
Frontend:
React.js
Vite
Tailwind CSS
Redux Toolkit
React Router
Axios

Backend:
Node.js
Express.js
MySQL
JWT Authentication
bcrypt.js
